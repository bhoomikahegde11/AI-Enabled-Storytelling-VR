# Level 1 HUD Prefabs Placeholder Folder

This folder contains placeholder prefabs for the Level 1 immersive game HUD system.

## Setup Instructions

To implement the HUD system, drag the corresponding GameObject hierarchies from the Unity scene into this folder to turn them into prefabs:

1. **SubtitlePanel**: Drag the subtitle display panel containing `speakerNameText` and `npcSubtitleText`.
2. **PlayerInputPanel**: Drag the panel containing the main `TMP_InputField` and `SendButton`.
3. **EconomyHUD**: Drag the panel displaying coins earned (`varahaText`), the `Slider` visual bar, and the respect text label.
4. **NPCIntroPanel**: Drag the panel used for showing customer identity cards (`introNameText` and `introOriginText`).
5. **TradeCompletePanel**: Drag the transaction ledger panel displaying trade summaries.
6. **CurrentTradePanel**: Drag the active deal metrics status tracker.
