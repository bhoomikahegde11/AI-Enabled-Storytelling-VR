# Level 1 Voice Recording Instructions

## Who records what
- Each teammate records only their assigned character CSV.
- One separate recorder handles `shared_variables_recording_sheet.csv`.

## Characters
- `lakshmi_amma`
- `chinnamma_naik`
- `saraswati_chetti`
- `abdul_rahman`

## File delivery rules
- Save every clip as `.wav`.
- Filenames must match the CSV exactly.
- Put clips in the Unity folder shown in the CSV.
- Do not add extra words before or after the scripted line.
- Do not add long silence at the start or end. Keep trims clean.

## Performance style
- Use natural spoken English.
- Do not sound polished British or royal.
- Keep the local characters grounded in Hampi bazaar life.
- Keep Abdul Rahman worldly and travelled, but still understandable.

## Placeholders
- Do **not** speak placeholders like `{spiceName}`, `{counterPrice}`, `{currency}`.
- Placeholders are handled by shared stitched clips.
- For `prefix` rows, record only the exact prefix shown in `spoken_text_to_record`.

## Prefix stitching
- Prefix clips are recorded once, then followed in playback by shared number/currency/spice/suffix clips.
- If the CSV notes say a prefix is compatible with multiple scenarios, record it only once.

## Shared recorder
The shared recorder should record:
- number clips
- currency clips
- spice clips
- quantity clips
- suffix clips

## Recommended workflow
1. Record one character sheet at a time.
2. Name files exactly as listed.
3. Export clean WAVs.
4. Place them into the Unity folder path listed in the CSV.
